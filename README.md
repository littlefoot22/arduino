# arduino

My Arduino sketchbook. Point the Arduino IDE's sketchbook location at this
folder so it picks up `hardware/` and `libraries/`.

| Folder | What's in it |
| --- | --- |
| `badges/` | Badge and wearable projects: 2021 touch-screen badge, badge3 bridge (with build photos), card, umbreon, astro, dolly |
| `bluetooth/` | HC-05 Bluetooth projects (`node`, `primary`) |
| `attiny/` | ATtiny85 RGB lights (`mood_light` with light sensor, `pot_rgb_light` with a potentiometer) |
| `learning/` | Small experiments and tests: blink, buttons, serial, shift register, NeoPixels, screens |
| `foxhunt/` | Fox-hunt radio app, built to WebAssembly (see its own README) |
| `hardware/` | ATtiny45/85 board definitions; must stay at the top level |
| `libraries/` | Adafruit NeoPixel library; must stay at the top level |
